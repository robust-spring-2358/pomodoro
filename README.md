# 番茄时钟微信小程序

一个简单好用的番茄工作法小程序：

- 工作 40 分钟 → 短休息 10 分钟，每完成 4 个番茄 → 长休息 15 分钟
- 圆环进度显示、开始/暂停/重置按钮
- 自动统计今日和累计完成的番茄数（保存在手机本地）
- 每次开始前可选「本次要做什么」（数学作业、语文作业、英语作业、书法、游戏、读书）
- 每完成一个番茄，自动记一行到「记录」表格：开始时间（北京时间）、计时时长、做的事情
- 「记录」页可查看表格、一键导出成 Excel 能打开的文件、清空记录
- 倒计时结束时震动提醒

## 怎么在电脑上运行它（照做就行）

1. 下载并安装【微信开发者工具】：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 打开微信开发者工具，用微信扫码登录
3. 点击左侧的【导入】，目录选择本项目文件夹（就是包含 `app.json` 的这个文件夹）
4. AppID 选【测试号】（不用注册，直接选），项目名称随便填
5. 点击【确定】，就能在模拟器里看到番茄时钟了

## 怎么在手机上体验

点击开发者工具顶部的【预览】，用手机微信扫码，就能在手机上打开（手机上才有震动提醒）。

## 想修改时长

打开 `pages/index/index.js`，最上面有一段：

```
const DURATIONS = {
  work: 40 * 60,       // 工作：40 分钟
  shortBreak: 10 * 60, // 短休息：10 分钟
  longBreak: 15 * 60   // 长休息：15 分钟
}
```

（这是你当前项目的设置）把 40、10、15 改成你想要的分钟数，保存后模拟器会自动刷新。

## 想修改颜色

同样在 `pages/index/index.js` 里的 `MODE_COLOR` 部分，把 `#ff6b6b` 这样的颜色代码换成你喜欢的颜色即可。

## 目录里都有什么（看不懂没关系，能跑就行）

| 文件 | 作用 |
| --- | --- |
| app.json | 小程序的"总配置"：登记了有哪些页面、顶部标题叫什么 |
| app.js / app.wxss | 全局的逻辑和样式，不用管 |
| pages/index/index.wxml | 页面长什么样（结构） |
| pages/index/index.wxss | 页面外观（样式） |
| pages/index/index.js | 计时逻辑（核心代码） |
| pages/records/ | 「记录」表格页：查看、导出、清空记录 |
| project.config.json | 开发者工具的配置文件，导入时自动读取 |

## 记录功能怎么用

1. 开始计时前，点一下时钟上方的下拉框，选择本次要做的事
2. 每完成一个工作番茄，会自动在底部「记录」页记一行：开始时间（北京时间）、时长、做的事（休息不记录）
3. 想导成 Excel：打开「记录」页 → 点「导出 Excel 文件」→ 在分享面板里选「文件传输助手」→ 在电脑微信里接收文件 → 双击用 Excel 打开即可

## 常见问题

- 电脑模拟器里不震动是正常的，真机预览才有震动
- 每次导入都选【测试号】即可，不需要注册 AppID
